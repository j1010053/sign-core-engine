## 1. 本體論與不變式

表徵 = **骨架(音段串)+ 韻律層 + 旋律層 + 兩種連結**。

- **韻律層(prosodic tiers)= 時間軌道**:mora、syllable、foot、pword。由 `Parse` 從骨架剖析而得,層間以**支配(domination)**相連——嚴格分層、相鄰、全覆蓋(時間無洞、不重疊、不亂序)。因與時間綁定,**內在有序**:序數(`nth` / `last` / `from right`)直接可用,不必進 Scan。
- **旋律層(melody tiers)= 時間乘客**:tone、nasal、ATR……不綁時間,只有**聯結(association)**到韻律錨點後才獲得時間位置。多對多、可浮游、無內在序——要序數必須進 `Scan` 借軌道。
- 每條旋律層另有一個**序列(sequence)**:自體段的固有線性順序(來自詞彙或造生時的插入位置),獨立於聯結。浮游者留在序列原位(D6)。

**純度不變式**:任何規則——條件可沿連結(聯結+支配)**唯讀**跨層,受局部性上界(D9);改動只能寫自己這層的物件與連結邊。凡「第幾個」的位置定址 → `Scan`(D3)。跨層整合只發生一次,在末端 spell-out(D1)。

```
旋律   tone:   H       L        (M)@3          ← 聯結:可浮游、多對多、NCC(警告)
                |       |
韻律   mora:    μ   μ   μ    μ
                |   |   |    |                  ← 支配:嚴格分層、全覆蓋、有序
骨架   seg:     a   a   a    k …
```

## 2. 韻律層(時間軌道)— 支配語彙

### 2.1 宣告與剖析

```
Prosody mora < syllable < foot < pword          # 階層與次序;可省略不用的層

Parse mora:     @vowel | @vowel :: @coda        # weight-by-position
Parse syllable: {p,t,k,s}? {l,r}? :: @vowel :: @cons?    # onset :: nucleus :: coda
Parse foot:     (<syl> <syl>&[+stress]) ltr     # 左弱右強(抑揚)
Parse pword:    <foot>+
```

匹配子:`<seg> <mora> <syl> <foot> <pword>`;界標:`.` 音節界、`|` 音步界、`$` 詞界。層級特徵沿用 `Feature (mora) …` / `Feature (syllable) …` 寫法。

### 2.2 結構動詞(動支配邊)

| 動詞 | 語意 |
|---|---|
| `parse <level>` | 依 `Parse` 宣告(重)剖析一層 |
| `reparse <level> [within …]` | 音段變動後局部重剖 |
| `dominate <上層單位> -> <下層單位> <方向>` | 加一條支配邊(結構修復用) |
| `release <上層單位> [from <下層>]` | 減一條支配邊 |
| `merge <單位> <單位>` | 結構合併(如兩莫拉併一音節) |
| `delete <單位>` | 刪除結構節點(支配關係隨之調整) |

**結構穩定性**:音段被刪時,其上的韻律節點行為由層級參數 `on-daughter-loss: keep-empty | delete` 決定;`mora` 預設 `keep-empty`(空莫拉是暫態、必須修復的節點,補償性延長之所本),其餘層預設 `delete`。剖析時機預設手動(`reparse` 顯式呼叫),可設 `reparse: auto`。

序數對韻律層免費:`<syl>2 from right`(倒數第二音節)、`last <mora>`。

## 3. 旋律層(時間乘客)— 聯結語彙

### 3.1 宣告

```
Melody tone  {H, L}   anchor mora
Melody nasal {+nasal} anchor segment
Melody atr   {+ATR}   anchor vowel
```

三要素:名字、**字母表**(值集合;層的實際狀態空間 = 值集合 ∪ {Ø})、**anchor**(乘客預設停靠的軌道層,可為自然類)。私有特徵(+nasal)與多值符號({H,L})完全同構:不鼻化、無調都是 Ø,不需負值(D12)。

可選屬性:

```
Melody tone {H, L} anchor mora:
    on-anchor-loss float          # D14:錨點被刪 → 浮游
    on-stray keep-in-place        # D6:浮游留在序列原位
    ocp off                       # 同層相鄰同值自動合併(預設關)
```

注意:**沒有 `default` 欄位**(D12)。預設值以顯式規則在你要的推導位置填入:`fill tone Ø => M within pword`——它是可排序規則,早填晚填會 feed/bleed 不同規則,這正是分析的一部分。

### 3.2 表徵:聯結圖 + 序列

一條旋律層對其 anchor 軌道構成二部圖;一條**聯結**是一條邊 `(自體段, 錨點)`。自體段狀態:已聯結 / 浮游(合法、可長期)/ 延展(一段多錨)。錨點狀態:承載 / **Ø(空=未指定)** / 多承載(輪廓調)。另有固有**序列**位置,浮游者留原位(D6)。

記法:`H~μ₂`(聯結)、`(H)@3`(序列第 3 位的浮游 H)、`H~μ₁~μ₂`(延展)、`μ:Ø`(空錨點)。

良構:NCC 不交叉,違反 → 警告(D7,`strict-ncc` 可調)。

### 3.3 動詞(動聯結邊)

原語兩個,其餘為具名特例:

```
associate <自體段> -> <錨點選擇>              # +1 邊
delink    <自體段選擇> [from <錨點選擇>]       # −1 邊(可致浮游)

spread <值> <leftward|rightward|bidirectional>
       [blocked-by <條件>] [within <疆界>] [through] [on-conflict <值|stop>]
dock   <自體段選擇> floating <方向|nearest> [to <錨點條件>]
shift  <n> <軌道單位> <方向>                   # 每條邊同步平移
merge  adjacent-equal                          # OCP 操作版
insert <值> floating [near <錨點條件>]          # 造新自體段(旋律造生)
delete <自體段選擇>                             # 刪自體段連同其邊
fill   <層> Ø => <值> [within <疆界>]           # 預設填入(把 Ø 錨點以新自體段補上)
```

spread 語意(整併 D8/D10/D11):方向必寫;只填 Ø 錨點,遇非 Ø 停下,`through` 才穿越(交叉→警告);`bidirectional` 兩側先到先佔,同拍衝突 → 錨點保持 Ø + 警告,交給 `on-conflict`。

### 3.4 讀取:可達性(D9)

條件用熟悉的 `X / 環境 _` 寫法,引擎自推層間路徑:最短可達優先;超出局部性上界(參數 `locality`,預設 `syllable`)即不可達、規則不觸發。讀 = 沿聯結+支配的內容定址,唯讀;遠距與序數 → `Scan`。

### 3.5 旋律的來源

詞彙給定(詞條自帶調型/鼻化,載入即在旋律層),或規則造生(旋律層規則沿支配鏈唯讀讀骨架條件、在自己層 `insert` 浮游自體段)。聲調產生即後者,是普通旋律規則,非跨層寫。

## 4. 疆界與型態括號

- `within <單位>`:規則作用疆界,與 anchor 正交。單位可為韻律層(pword、foot——由 §2 剖析,隨時可用)或型態單位(stem、root、word)。
- 型態單位**不由音系推導**:由型態層(架構書 Morphology stratum)以括號餵入,如 `[[kitaːb]root -aːt]stem`。音系唯讀這些括號當疆界。詞條若未保留型態切分,`within stem` 類規則無法界定範圍——引擎應在載入時檢查並警告。

## 5. Scan(全域位置存取)

唯一允許位置定址(序數/計數/全域量化)的建構,三道鎖 + 枚舉範圍:

```
Scan tone along mora within pword from right [over linked-only]:
    <塊內規則:nth / last / count / 序列相鄰 可用>
```

- `along`:借哪條**韻律軌道**的序報數。預設 = 該旋律層的 anchor 層;可顯式改粗/改細(`along syllable` 掃 anchor 為 mora 的 tone 時,每個音節刻度報告一個調簇)。
- `within` / `from`:疆界與定序方向。
- `over linked-only`(預設,D4):沿軌道逐刻度報告承載者,浮游者不入列;`over all` 時浮游者按序列原位插入。空刻度以 Ø 入列——因此「第一個無調莫拉」可定址,這是 Bantu 指派規則的關鍵。
- 塊內「相鄰」一律指**沿掃描軸的序列相鄰**(D5)。
- 塊內動詞同 §3.3,但選擇子可用序數。

## 6. Spell-out(末端整合)

整段推導期間旋律永不寫回音段。全部規則跑完後,一次拼讀:

1. 沿骨架逐錨點收集其承載的旋律(含輪廓=多承載);
2. 仍為 Ø 的錨點依該層此時是否已被 `fill` 決定表層值,未填者依 `on-unrealized-empty: bare | error`(預設 bare:不帶該特徵);
3. 仍浮游的自體段依 `on-unrealized-floating: drop-warn | error`(預設 drop-warn);
4. 壓平為線性語音串 → romanizer。

中間 `romanizer-xxx` 需要顯示旋律時,對該階段做一次**快照拼讀**(不改動表徵)。


## 8. 範例集(每步標註類別)

### 8.1 聲調產生(tonogenesis)+ 三分系統

```
Melody tone {H, L} anchor mora

tonogenesis:                                   # 旋律規則(唯讀讀骨架,寫自己層)
    insert H floating near mora / onset&[-voice] _
    insert L floating near mora / onset&[+voice] _
dock-tone: dock floating nearest               # 旋律規則
devoicing: [+voice]&onset => [-voice]          # 音段規則(對立已轉入旋律層)
fill-default: fill tone Ø => M within pword    # 後期預設填入(可排序!)
```

\*pa→pá、\*ba→pà;無來源音節保持 Ø 直到 `fill-default` 才浮現 M——填入時機前的任何規則看到的都是「無調」,H/L/Ø 三分自然成立。

### 8.2 鼻化和諧(私有特徵 + 阻塞)

```
Melody nasal {+nasal} anchor segment
nasal-spread: spread +nasal rightward blocked-by [-sonorant] within pword
```

只填 Ø 錨點、遇非響音停;「−nasal」不存在,不鼻化即 Ø。

### 8.3 聲調穩定 + 位移(D6/D14)

```
final-vowel-loss: @vowel => * / _ $     # 音段規則;其調浮游,留在序列原位 (H)@n
redock: dock floating leftward           # 旋律規則:左掛鄰莫拉(連調)
tone-shift: shift 1 mora rightward       # 或整層右移
```

### 8.4 補償性延長(支配語彙,與聯結語彙明顯分家)

```
coda-loss:   @coda => * / @vowel _ .            # 音段規則;mora 依 keep-empty 留空節點
repair-mora: dominate <mora>&empty -> @vowel leftward   # 結構動詞:空莫拉向下重掛
# 拼讀時雙莫拉元音 → 長元音
```

對照 8.3:結構的「空」是必須修復的暫態(dominate);旋律的「浮」是合法常態(dock)。兩套動詞讓這件事在語法上一眼可辨。

### 8.5 ATR 雙向和諧(D10/D11)

```
Melody atr {+ATR} anchor vowel
atr-spread: spread +ATR bidirectional within stem on-conflict stop
```

由詞根向兩側,先到先佔;同拍衝突 → 錨點留 Ø + 警告(此例選 stop,不另賦值)。`within stem` 需要詞條帶型態括號(§4)。

### 8.6 Bantu 三連發(Scan)

```
# (a) 倒數第二音節指派 H
Scan tone along syllable within pword from right:
    associate H -> <syl>2

# (b) Meeussen's Rule:序列相鄰的 H…H,後者變 L(掃描軸相鄰,中間無調莫拉不算)
Scan tone along mora within pword from left:
    H => L / H _        # 此處相鄰 = 沿 mora 軸的序列相鄰(D5)

# (c) 指派 H 到第一個無調莫拉(Ø 可定址)
Scan tone along mora within pword from left:
    associate H -> first mora:Ø
```

三例都動用「第幾個/序列相鄰/全域找 Ø」——正是被關進 Scan 的位置定址,塊外寫不出來,也不該寫得出來。

## 9. FST 邊界與開放問題

- **可編譯性分層**:§3 旋律規則(受 locality 上界)≈ 正則,候選編譯;§2 剖析類正則;`Scan` 與 spell-out 為標記的非正則點,永久直譯器。批次演化與反向重構對含 Scan 語言的覆蓋率列為持續評估。
- **feature geometry(D13)**:MVP 後作為進階選項——特徵樹宣告、類節點 spread、同宿主互動(鼻化壓調、喉部 register);MVP 內以扁平特徵 + 跨骨架中介涵蓋。
- **待收斂細節**:`reparse: auto` 與旋律規則的交錯時序;extraprosodicity(邊緣不可見)是否需要;`on-conflict` 允許引用具名規則而非單一值;快照拼讀在演化樹視圖的呈現粒度。
