## 交叉映射:哪個實例測哪個機制

一個機制常被多來源的案例共同驗證,交集處是最該優先實作的:

- **construction=sign** ← 折磨 5/8/18 + 實例 1/3。地基,先綠。
- **Store fork vs D version** ← 折磨 7 + docs/09 §7 職責裁決。
- **兩種構詞(component vs tier 聯結)** ← 折磨 3/6/15(component)vs 17/18(phon tier);實作紅線(docs/09 §5)。
