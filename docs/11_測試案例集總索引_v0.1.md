## F. 外部驗證資料集(現成 benchmark,分三層用)⚪

不用自造、學界/業界已有的驗證資料。授權不一——**當測試資料用(本地跑、不重新散布)多數可行;打包進軟體須逐一查**,同 Lexurgy 語料(submodule/下載腳本,不 vendor)。

**第 1 層 — 迴歸/相容(測「不退步」):**
- Lexurgy 社群規則庫(=E 節)—— 測相容性,非正確性。

**第 2 層 — 黃金測試(測「引擎正確性」;最有說服力):** 用有文獻記載的真實歷史音變,replay 祖語詞驗證得到正確後代形。
| 資料 | 網址 | 測什麼 | 備註 |
|---|---|---|---|
| **Latin → Romance**(建議第一個) | (文獻/Wiktionary 詞源) | 完整音變鏈 replay(*focus*→西 fuego/法 feu/義 fuoco) | 記載最完整;**標為 M2 首個外部 golden test** |
| PIE → Latin/Greek/Sanskrit | (Wiktionary/LIV) | Grimm's Law 等、規則排序 | |
| 中古漢語 → 現代方言 | Baxter-Sagart(數位化重構) | 聲調演化(對照 8.1 tonogenesis) | |
| Proto-Bantu → Bantu | **BLR** Bantu Lexical Reconstructions | 聲調 sandhi、Meeussen(對照 8.6) | |
| 反向重構同源詞 | **loanpy**(github) | FST 反向重構(匈牙利/烏戈爾語料) | 對照 DSL 反向能力 |

**第 3 層 — 分佈合理性(測「自動決策像不像自然語言」):**
> **前提:僅在自動演化模式下適用。** 此層測的是**自動決策品質**,非引擎正確性——兩者分屬不同測試層。**手動造語模式豁免**:使用者有權造類型學上罕見/極端的語言(創作自由;Ithkuil 式設計合法),此時不以 WALS 分佈糾正。呼應鐵律:資料層不做類型學判斷,合理性僅為**自動生成器**的內部評分準則。

| 資料 | 網址 | 測什麼 |
|---|---|---|
| **Grambank** | https://grambank.clld.org | 自動演化產物的特徵組合是否落在真實語言分佈內(如「後綴+OV」和諧) |
| **WALS** | https://wals.info | 詞序和諧、Greenberg 共性;自動模式產物不違反 |
| SemEval-2020 Task 1 | (SemEval) | 歷時語意變化 benchmark;驗 drift/prototypicity 表示合理性 |
| UniMorph / SIGMORPHON | https://unimorph.github.io | 屈折範式、suppletion(對照折磨 14) |
| DeriNet / CatVar | (github) | 派生詞族 DAG(對照 component/origin) |

實作對應:第 3 層測的是 **B 自動路徑選擇 + 文法檔自動模式 + E 先驗抽樣** 合起來的產物,ground truth = Grambank/WALS 真實分佈。**啟用條件 = 干涉光譜設為自動**(架構書 §2);手動/輔助模式不觸發此層。

## 交叉映射:哪個實例測哪個機制

一個機制常被多來源的案例共同驗證,交集處是最該優先實作的:

- **透明度(transparency)一個欄位** ← 折磨 6(火車)+ 實例 7(隱喻固化)+ 實例 1(複合)+ 實例 5(緊密度)。四案共測,高優先。
- **split/merge + 最小演化單位=維度** ← 折磨 1/13 + 實例 2/9 + B 原語 Split/Merge。
- **construction=sign** ← 折磨 5/8/18 + 實例 1/3。地基,先綠。
- **Store fork vs D version** ← 折磨 7 + docs/09 §7 職責裁決。
- **兩種構詞(component vs tier 聯結)** ← 折磨 3/6/15(component)vs 17/18(phon tier);實作紅線(docs/09 §5)。

## 動工順序建議(依測試出口)

1. **M0 步驟 2–6**:出口 = A 組 8.1→8.6 逐案綠燈(當前程式碼直接延續)。
2. **Sign 引擎**:出口 = B 組折磨測試逐案通過(先綠 construction=sign 的 5/8/18)。
3. **B/D/E**:各以 C 組十實例對應項為端到端出口。
4. **Lexurgy 黑盒**(E 組):M2,匯入器 + 白名單。
5. **外部黃金測試**(F 組第 2 層):M2,Latin→Romance 完整鏈為首個——證明引擎能重現真實歷史音變(最強正確性證據)。
6. **分佈合理性**(F 組第 3 層):待 B 自動演化模式可跑後,用 Grambank/WALS 驗自動產物;**手動模式不適用**。

每階段不設「無測試出口的步驟」(CLAUDE.md 原則)。
