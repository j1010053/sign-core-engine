## 4. 裁決結果(擁有者 2026-07-13)

1. **語法遷移邊界(已裁決)**:`feature`/`symbol`/`class`(音段/特徵系統宣告)**留 dsl 域,
   維持 Lexurgy 形**;Language 的 Definition(`=`)**只管 dsl 不認識的概念**——prosody/
   受控範疇/trait/global/sign。**同名不同域靠檔案區域(語境)區分,非關鍵字區分**
   (規則檔區域 = dsl 文法;.lang 的 Definition 區 = language 文法)。
2. **crate 佈局(已裁決)**:`build_word` 與循環套用的**協調邏輯**在 language crate
   (依賴 dsl 型別);executor/lifecycle/primitives/verbs **留 dsl 側不動**。
   接口:`language::build_word / compile_phon_rules → dsl::Word / RuleSet → dsl::run`,
   單向依賴。(dsl 保留現有簡版 build_word 供路徑 A 獨立模式。)
3. **docs 回填(已裁決)**:不逐檔回填;**以最新檔案(彙整+鳥瞰+修補05)為基準**,
   舊文件出入處以其為準。
