# 接觸痕跡只在節點層,與語言聯盟未建模(v0.1)

> **狀態:問題陳述,未裁定。** 本檔不新增 P 編號,亦不提出實作方案。
> 起因:步驟 21-4 決定分群策略時,查證「語言聯盟該不該影響分群」,
> 發現它**在整個 `docs/` 裡一次都沒出現**,而追下去牽出一組相關的表達缺口。
>
> 承 `演化圖本體論_v0.1` §3.2(來源光譜)、§4(Nativization)、§6.2(互通度)、
> P16(12 項 Atomic Rewrite 為封閉內建集)、P62 §7.1(donor 指名借入)。

---

## 0. 一句話

**接觸的痕跡只記在節點層(誰跟誰借),沒記在內容層(哪一條規則/哪個詞是接觸來的)。**
語言聯盟因此表達不出來——不是分群算法選錯,是證據沒被記錄。

---

## 1. 目前記得下什麼

| 機制 | 記在哪 | 雜湊 | 型別 | 語意 |
|---|---|---|---|---|
| `.chg` prelude 的 `donor <alias> <node-id>` | 主幹邊的 changeset | **內** | **node id**(P58 內容雜湊) | 這次演化跟哪個節點借 |
| `Edge::reference` | 節點的 `parents[1..]` | **內** | node id | 我的內容是含那個節點的合併(克里奧爾) |
| `sign.provenance = loan` | sign 本身 | 內 | 枚舉 | 這個詞是外來的 |
| `EvolutionState.contacts` | `nodes/<id>/state` | **外** | **自由字串** | 與誰、何時、多密切(可能沒借到詞) |

前兩者是 replay-derived,故任何依賴它們的視圖**不必進 authoring 失效線**
(`資訊流D應用層框架` §6.1)。`State.contacts` 則相反——但它刻意用自由字串,
因為「接觸對象常是本專案外的真實語言或未建模的族群」,所以它**餵不進圖分群**。

---

## 2. 三個缺口

### 2.1 `Adopt` 不設 `origin`——借來的詞說不出跟誰借的

`rewrite.rs` 的展開:

```rust
Ok(vec![insert_sign(
    document,
    borrowed.clone().with_provenance(source.provenance()),
)?])
```

只設 `provenance`。於是:

- **節點層**知道跟誰借(`.chg` 的 `donor`);
- **詞層**只知道「我是借來的」,不知道來源。

連帶後果:`query::derivation_family` 接不起借詞的世系——`origin` 是空的,
家族在借詞這裡斷掉。

**而系統明明為此留了口子**:`validate_origin_graph` 對**限定名**放行——

```rust
if !origin.0.contains("::") && !names.contains(origin.0.as_str()) { /* META_ORIGIN_UNKNOWN */ }
```

帶 `::` 的 origin 不受「必須存在於本地」檢查,那顯然是為跨語言來源準備的。
但**引擎裡沒有任何東西產生它**,只有手寫 `.lang` 寫得出來。
`crates/query/tests/derivation.rs` 的跨語言 origin 測試用的就是手寫的。

> **待裁**:這是缺口還是刻意?`Adopt` 的註解說「借詞是**造了一個新詞**,
> 不是 donor 那個詞跑過來繼續演化」——若照此,借詞不該有 origin,那麼
> `::` 豁免就是個**沒有生產者的逃生口**,該補生產者或該拿掉。兩者擇一。

### 2.2 規則借用不留痕跡

`AtomicRewrite::SoundChange { home, body }` 加得了規則,**但不帶 donor**。
`Adopt` 只借 sign。故:

**「這條規則是跟鄰語趨同來的」現在寫不下來。**

而語言聯盟的定義核心正是**結構特徵**的共享(見 §3),不是詞彙借用。
少了這個,聯盟的證據在資料層根本不存在。

### 2.3 接觸只有單向,沒有「彼此變像」

`donor` 是有向的:A 跟 B 借。`Edge::reference` 是匯流的:C 由 A、B 合成。
兩者都沒有「A 與 B **各自**演化,結果彼此變像」這種形狀——那不產生新節點,
也不是任一方向的借入。

## 3. 語言聯盟是什麼(repo 缺,補記)

**Sprachbund / 語言區域**:地理相鄰但**非同源**的語言,因長期**雙向**接觸而
趨同,共享一組結構特徵,且那些特徵**無法由共同祖先解釋**。

判準三條:

1. 特徵是**結構性**的(音系 / 型態句法),不只是詞彙借用;
2. 涉及**多個**語言(通常 ≥3),不是雙語配對;
3. 不能追溯到共同祖先或單一供體。

實例:巴爾幹語言聯盟(後置冠詞、不定式喪失、「意欲」型將來時)橫跨阿爾巴尼亞語、
羅馬尼亞語、保加利亞語/馬其頓語、希臘語——分屬四個不同印歐語支;
南亞的捲舌音與 SOV 跨印歐與達羅毗荼兩個語系。

### 3.1 與已建模的兩者對照

| | 拓撲 | 產物 | 借什麼 | 方向 |
|---|---|---|---|---|
| **借入**(donor) | 有向邊 | 原語言 + 幾個外來詞 | **詞** | 單向 |
| **克里奧爾**(多親) | 匯流節點(§1「唯一的拓撲例外」,預設不啟用) | **一個新語言** | 詞彙 + 語法,來自不同祖先 | 匯流 |
| **語言聯盟** | **無拓撲** | N 個語言**各自**變像 | **結構特徵** | 雙向、多方 |

§3.2 的「來源光譜」把 native / contact / fusion / simplification 說成同一機制
「**引用了誰、引用多少**」的程度差別——但那個光譜的參數全部沿**入邊**。
語言聯盟沒有入邊,所以那個光譜表達不了它。**它不是光譜上的一點,是另一個維度。**

## 4. 對分群的結論(已落地)

先前一度以為「`ConnectedComponents`(任意 pair 的連通分量)才抓得到語言聯盟」。
查證後這是**假問題**:

1. `演化圖本體論` §6.2 已明文定義
   > **方言連續體 = 樹上一組互通度高於某閾值的鄰近點**

   「樹上」「鄰近點」直接就是沿演化邊切,即 `TreeEdgeCut`。**規格已定,不是取捨。**
2. **沒有任何分群策略抓得到語言聯盟**——抓不到的原因不是算法選錯,是 §2 的證據缺口;
3. 拿 donor 邊當分群候選邊會把「借了三個詞」和「同一支方言」當成同一回事。

故步驟 21-4 實作 `TreeEdgeCut`,**不做 contact 版**。
`DialectGroupingStrategy` 是可替換接口,日後補策略不需改既有程式碼。
