## 1. P 系列決策總表（權威）

**決策狀態**：下列 P20–P64 均為現行決策。

### 1.1 修補 05：Primitive 與檔案格式（P20–P28）

| 編號 | 落地 | 最後有效決策 |
|---|---:|---|
| **P20** | 🟢 | **音變 DSL 是獨立可分軟體**。依賴方向固定為 `changeset → language → dsl`；DSL 只知 `Word`，不得依賴 Sign／Trait／Language／ChangeSet。Compiled Grammar 的 phon 側必須是 DSL 可直接執行的規則集，主引擎與獨立引擎須做雙軌迴歸。 |
| **P21** | 🟢 | **IR dump 採 Language canonical form + progressive lowering**。Source→Expanded→Resolved→Ordered 都是合法 Language；僅 Codegen 產生 Compiled Grammar。printer 必須確定且 round-trip 無隱藏狀態。 |
| **P22** | 🟢 | **條件語法共用 `/`、Path 與有界布林組合**。phon 域使用 linear/tier-relative environment；language 域使用具名 anchor 的 Path。不得擴成有量詞、計算或副作用的通用查詢語言。`else` 的最後語意由 P43（非 phon）與 P46（phon RuleBlock）分域精化。**language 域的 Path 已由修補13 ⑨ 縮減為 `Anchor ('.' Name)*`**——`[key]`／`~tier` 兩種段零生產者且查找端不解讀結構;dsl 域的序數與 tier 記法不受影響。 |
| **P23** | 🟢 | **Primitive Edit 只有 `insert / delete / update / move`**。`update`、`move` 保持節點身分；`delete+insert` 表示生滅，不能冒充更新。12 個 Atomic Rewrite 必須可降成四原語。 |
| **P24** | 🟢 | **引用是節點欄位中的 typed Ref，不是第二套圖邊**。改引用就是 `update(field, Ref)`；必驗懸空引用、component DAG 與 origin 鏈。 |
| **P25** | 🟢 | **授權端定址共用 Path，插入位置用 stable anchor**：`start/end/before:/after:`，不以會漂移的裸索引作 replay 契約。resolve 後由 P26 的穩定 id 承接執行。 |
| **P26** | 🟢 | **直譯器必須可決定性 replay**：id 純序列配發；每 statement 展開的 edits 原子提交；提交後跑 `check_language()`；修改只標 dirty，導出前 lazy compile。 |
| **P27** | 🟢 | **Trait 的 `==` 是 `Block` 節點，不是分隔 token**。Trait 可在 Block 或 Item 粒度操作；此決策不要求 sign 保存同形 block。 |
| **P28** | 🟢 | **ChangeSet 的結果是 Language**。Language 有永遠存在的 canonical empty root；Language 源文字與「對空 Language 施作的一串 insert」互為對偶，輸出回到同一 canonical 格式。 |

### 1.3 修補 07：共時四維系統（P38–P44）

| 編號 | 落地 | 最後有效決策 |
|---|---:|---|
| **P38** | 🟢 | **phon/syn/sem/prag 的內容、規則、patch 分維，但分類樹只有一棵且維度中立**。共享 Sign 身分、Refs、Defs、parser/resolver/diagnostics/serialization。Morphology 不是第五維。此 v0.2 裁決取代早期「四棵 ontology」表述。 |
| **P39** | 🟢 | **Defs 是單一資訊源**；四維 projection 都是 typed view，不另存副本。修改走各維 typed patch `Sign × Patch → Sign′`，不得暴露可變 projection。 |
| **P40** | 🟢 | **`belongs` 統一成員、trait 展開與分類標記**。其閉包須遞迴、去重、抓循環、處理本地覆寫並保留來源 diagnostics；slot filler 以 belongs 閉包驗證。 |
| **P41** | 🟢 | **Valence 是 slots 結構，不是整數欄位**。第一版 slot 包含名稱、filler 所需 trait/type 與 optional；預設必填，不預先擴成完整 constraint language。 |
| **P42** | 🟢 | **Construction 也是 Sign**。它帶 slots 與四維內容；填 slot 產生暫態 derived Sign，不就地修改原 construction，變價由 typed slot mapping 表達。 |
| **P43** | 🟢 | **syn/sem/prag 的 `Else` 以每一 Sign/token 為求值單位，結果三分**：Matched、Unmatched、Error。identity rewrite 仍是 Matched；Error 不得落入 Else。 |
| **P44** | 🟢 | **每維規則只直接修改自己的 projection**。跨維結果須由 construction 或更高層協調；執行紀錄保留 matched/changed/diagnostics/source location/deterministic order。 |

### 1.4 修補 08–09：具名節點與 phon block（P45–P46）

| 編號 | 落地 | 最後有效決策 |
|---|---:|---|
| **P45** | 🟢 | **Rule／TypedCase／CaseBranch 可帶可選標籤，供 authoring keyed path 使用**。一般維度使用 `@name` 後綴與 `rule["x"]` 等 selector；標籤不是身分，resolve 後仍釘 P25/P26 的 stable id。sign 內不恢復具名 `==` block。 |
| **P46** | 🟢 | **phon 命名與 block 語法對齊 Tshiatūn/Lexurgy `.qy`**：`name:` 前綴、結構化 Leaf／Then／Else／Propagate、grouped braces codegen。phon 是 P45 surface syntax 的分維特例；Propagate 為透明 wrapper，不占 identity address。flat→structured 必須顯式 `.phon_block:`，不得由普通 insert 偷渡。 |

### 1.5 修補 10：歷時 function 層與載入（P47–P55）

| 編號 | 落地 | 最後有效決策 |
|---|---:|---|
| **P47** | 🟢 | **層①是 statement；層②③④統一寫成 `name(args)`**。層級由 resolve 的名字決定，不靠關鍵字；resolve 後仍降成 primitive-only `ResolvedChangeSet`。 |
| **P48** | 🟡 | **Recipe/Goal 不是語法關鍵字，而是 package `code/` 的分工**。body 沿用 case／when／choose／序列，function 可互呼但必須檢查循環；std 無 guard sequence 的最小 runtime 已落地，完整 guard／State／選擇 runtime 留 Step 17。**分支語意由 P69 修訂**（`specifications/function分支語意與選擇層_v1.0.md`）：`when:` 為 accumulate（所有 Matched 都執行，同 `.lang`），候選列舉獨立為 `choose:`，`else` 為 `!any_matched`。 |
| **P49** | 🟡 | **function 定義住 `code/*.chg`**，採 definition-file mode：有 package header、無 base digest、只含 function。loader 以有序 `(path, source)` 逐檔解析，std 已拆成 `recipes.chg`／`goals.chg`；不由檔名推斷語意。 |
| **P50** | 🟡 | **沿用 P29 auto-discovery，否決顯式 import**。可重現性靠 library lock；function export、複數 data paths、`.chg` code 與 definition mode 必須共用現有 package 機制。**增修 A(2026-08-04,《修補06》§8.5)**：所否決者為 **`.chg` prelude 內的 import 語句**(原文所列 `import <ns> sha256:` 仍禁)；**專案層的 `project.toml` import 表不在禁令內**——它雜湊外、不進 replay，解析結果照樣經第三道 digest 入鎖，可重現性理由不適用。 |
| **P51** | 🟡 | **Recipe 逐步接力展開，不對同一 base 做快照展開**。無 guard sequence 已以兩次 entrenchment 證明下一步讀前一步結果，並維持失敗不部分提交；guarded／service 路徑仍留 Step 17。 |
| **P52** | 🟡 | **語法化路徑庫 = 少量參數化 function(code) + 多筆路徑表(data)**，不是每條路徑各寫一個 function。 |
| **P53** | 🟡 | **Atomic Rewrite 展開入口預留 `ServiceContext`**。donor 不走此介面（P63）；live service、History 與 pause/resume 留 Step 17。 |
| **P54** | 🟢 | **`fuse` 必須保存多個 `components` Ref**；`origin` 仍是單一來源，兩者不得混用。少於兩個 component 是驗證錯誤。 |
| **P55** | 🟢 | **`.chg` statement 標記 canonical 為 `#N:`，註解統一 `/* … */`**。舊 `statement N:` 可讀但 printer 一律輸出新形；交易與 digest 契約不變。 |

### 1.6 修補 11：演化樹節點模型（P56–P64）

| 編號 | 落地 | 最後有效決策 |
|---|---:|---|
| **P56** | 🟢 | **節點保存 immutable snapshot，edge 保存 changeset**。snapshot 只能由 parent merge + edge changeset 產生；讀狀態 O(1)，`verify/fsck` 可重算。此決策覆寫 docs/06 早期「節點不存副本」的實作面。 |
| **P57** | 🟢 | **rebase 依 typed `ReplayError` 分類，不比對訊息字串**。先更新 base identity 以進入 replay，再區分 Conflict／Broken input／Environment／Clean，並保留 statement ordinal。 |
| **P58** | 🟢 | **NodeId 採 node-v2 內容定址**：snapshot source digest、identity manifest digest、完整 parent edge（from + changeset digest）與 nativization 都進 hash；label 不進身分。 |
| **P59** | 🟢 | **digest 的職責是跨系統防掉包及 rebase 入口**。Step 14 的三道 digest 與 primitive-only 執行契約不改。 |
| **P60** | 🟢 | **snapshot 持久化採共享 content-addressed object store**。sign／global／trait／identity manifest／changeset 依 canonical content 去重；filesystem 僅存在 `conlang-persistence` host crate。 |
| **P61** | 🟢 | **多 parent 在節點 changeset 前做機械 3-way merge**。有穩定鍵的 signs／traits／distribution 逐項合併；dsl_decls 整塊比較；無唯一 LCA、雙邊異值、id/name collision 都明確失敗。融合保 id，借詞發新 id。 |
| **P62** | 🟢 | **跨語言選擇以 `ContactInjection`／`donor <alias> <node-id>` 落地，不新增接觸邊**。`adopt` 來源由引用派生；指名及清單形已實作，條件式集合選擇刻意延後。 |
| **P63** | 🟢 | **donor 與 library lock 同類，由 `DonorSpec` 注入；不得塞進 `ServiceContext`**。可見範圍只含 parents 與本節點 donor 宣告，四原語本身必須持有完整 payload、不得回頭查外部資料。 |
| **P64** | 🟢 | **節點以 folder 儲存，內容雜湊內外明確分界**。manifest／edges／snapshot identity 屬 immutable content；annotation／host config 可變且 hash-external。任何會改變 Language 狀態的資訊必須在 edge 上。 |
